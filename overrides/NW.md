# NW Studio
Adaptación local de OpenReel Video con identidad carbón y marfil inspirada en la referencia visual del usuario.

Inicio: `pnpm dev`
Comprobación: `pnpm --filter @openreel/web typecheck`
Build web: `pnpm --filter @openreel/web build`

La capa visual está en apps/web/src/nw-theme.css. Se mantienen los formatos, motores y paquetes originales para preservar compatibilidad. El código original conserva su licencia MIT en LICENSE.
